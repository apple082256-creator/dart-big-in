데이터 게이트는 통과했지만 현재 상태를 승격 후보로 제안하지 않는다. 남은 예외는 다음과 같다.

   현재 프로젝트 설계대로 구조화 KPI 행은 생성하지 않았다.
2. 전체 회귀 테스트 중 운영 기준선이 부분 KPI 적재 상태라는 사실과 전체 재물질화 테스트의

   대조해 실제 부호 반전임을 확인했다. 두 접수번호와 계산 근거를 보존하고 `approved`로 확정했다.
   판정은 `_has_unverified_sign_conflict`에 반영해 재실행해도 유지된다. staging 사본에서 두 행을
   지우고 `apply_industry_kpis(years={2026}, persist_profiles=False)`로 다시 만들면 final과 전 컬럼이
   일치한다(차이 0). 변경 전 DB는 `final/financial.before_ocf_approval_20261011_194217.db`에 있다.
