구현 방식:
- 일반 규칙을 넓히지 않았다.
- 입력값을 고정한 명시 목록 `src/db/verified_quarter_overrides.py`에 있는 경우만 계산한다.
  - 같은 태그 6건: 사실값 단계(`period_normalizer` 2단계)
  - 다른 태그 4건: 지표 단계(`derive_verified_metric_quarters`)

- 결과는 DERIVED로 저장하고 FY/Q3 값, 태그, 접수번호, 근거를 기록한다.
- 부호 정렬값은 FY 보고서의 표기 규칙을 따른다. 기존 보정 10건과 같은 방식이며, 카카오뱅크 비용 2건이 음수인 이유다.
